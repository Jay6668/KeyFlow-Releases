# KeyFlow

**Windows 实体交互学习舱，推荐搭配 EasyInput 八键＋旋钮开发板使用。**

将英语听词、真人例句、听力短题组与逐句训练串成学习流程，并提供中级会计知识训练、判断案例、今日任务和复习。电脑或耳机负责音频输出，开发板负责操作和状态提示。

## 下载和安装

在右侧 **Releases** 下载最新 `KeyFlow-版本-Windows-x64.zip`，解压后双击 `Install.cmd`。安装到当前用户目录，桌面入口为 **KeyFlow**。可用 `SHA256SUMS.txt` 校验下载文件。

需要 Windows 10/11 64 位与 Microsoft Edge WebView2 Runtime。例句检索、外部网页和首次运行环境准备可能需要联网。

安装保留已有学习数据与完整 EnglishContent。关闭 KeyFlow 后升级；程序备份位于 `%LOCALAPPDATA%\KeyFlow\release-backups`。本安装器不会清空学习进度。

## 推荐与开发板结合

- 八键：按当前学习阶段进行重播、判断、揭晓、作答、继续等操作；请看界面上的实际键位说明。
- 旋钮：短按切换调速，旋转以 0.5 倍步进调节 0.5–2.5 倍；逐句模式可切换上一句/下一句，长按重播。
- 灯光：学习播放、等待、完成等状态反馈，需要兼容的板端灯控能力和已配对设备。
- 保留 EasyInput 客户端及既有配置。应用前台处理已知合成板键，不要求修改固件或全局快捷键。
- 没有开发板也可以用界面按钮学习；硬件交互是推荐体验。

首次播放外部休息页面可能需要点击页面启用声音。智能魔方通过独立 CubeDesk 应用入口打开；CubeDesk 自己控制魔方和其灯光流程。
